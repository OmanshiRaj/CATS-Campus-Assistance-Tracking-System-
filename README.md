# CATS-Campus-Assistance-Tracking-System-
CATS (Campus Assistance & Tracking System) is a full-stack MERN web application designed to streamline everyday campus support tasks into a single, unified portal. Built for students and staff alike, CATS allows users to report and track lost items, submit and monitor complaints through a transparent status-history timeline, and manage their own profiles — all secured behind JWT-based authentication. The platform emphasizes simplicity and reliability over feature bloat: rather than trying to replicate every module of larger campus-portal systems, CATS focuses on doing a small set of core actions — reporting, tracking, and resolving — exceptionally well. Its name reflects this focus: it's not just a directory or a bulletin board, but an active system that assists users in getting issues seen and tracks them through to resolution, giving both students and administrators visibility into what's outstanding and what's been resolved.
